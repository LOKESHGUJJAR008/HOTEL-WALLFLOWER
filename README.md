# Hotel Wallflower, Kota — Luxury Boutique Hotel Website

A modern, responsive, boutique luxury hotel website built for **Hotel Wallflower** in Kota, Rajasthan. Crafted with a refined aesthetic combining a light-blue/crisp white foundation, deep midnight navy accents, and warm luxury gold highlights.

---

## 🌟 Key Highlights & Design Features

- **Sticky Horizontal Navbar**: Transitions smoothly from transparent over the hero to solid frosted glass on scroll. Complete with responsive mobile drawer navigation.
- **7 Comprehensive Pages**:
  1. `index.html` — **Home Page**: Hero with booking bar, 5-feature strip, 4 featured room cards, Kota City showcase (Seven Wonders, Kishore Sagar), 4 hotel experience highlights, Wallflower Advantage with interactive guest review slider, and live countdown offer banner.
  2. `rooms.html` — **Rooms & Suites Page**: Filterable room directory (by guests and bed type) with interactive room detail modal, photo carousel slider, specifications, and direct booking CTA.
  3. `dining.html` — **Dining & Bar Page**: "The Wallflower Bistro" fine dining and "The Velvet Lounge & Bar" with operating hours, signature menu highlights with category tabs, and table reservation modal.
  4. `amenities.html` — **Amenities & Recreation**: 10 comprehensive amenities grid (Fiber WiFi, Free Valet, 24x7 Desk, Room Service, etc.) and spotlights for the Billiards / Pool Table Lounge and Fitness Gym.
  5. `gallery.html` — **Photo Gallery**: Category filter tabs (Rooms, Dining, Lobby, Recreation, Kota City) with interactive Lightbox viewer.
  6. `about.html` — **About & Location**: Story of Hotel Wallflower, core values, distance guide to Kota landmarks (City Mall, Kishore Sagar, Airport, Kota Junction), and Google Map embed.
  7. `contact.html` — **Contact & Booking Enquiry**: Full reservation enquiry form with WhatsApp integration, contact details, FAQ section, and interactive map.
- **Floating WhatsApp Widget**: Pulsing quick-connect button on all pages with pre-filled enquiry messages.
- **Zero Heavy Frameworks**: Pure HTML5, modern CSS3 (Custom Properties & Grid/Flexbox), and Vanilla JavaScript for ultra-fast load times.

## 🚀 Getting Started

To view the website locally:

```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
